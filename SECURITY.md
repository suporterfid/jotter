# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Email **suporterfid@gmail.com** with:

- what you found and which part of Jotter it affects (route, command, or file);
- steps to reproduce, or a proof of concept;
- the version or commit you tested.

Expect an acknowledgement, then a fix and a note in [docs/security-audit-2026.md](docs/security-audit-2026.md) once the issue is closed. Past findings and their fixes are recorded there.

## Scope

Jotter is self-hosted software. Issues in your own hosting, PHP configuration, or credentials are outside this policy, but a Jotter default that makes them easy to get wrong is in scope.

## Supported versions

Fixes land on `main`. Run the latest release.

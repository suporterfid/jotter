# Jotter i18n (PT-BR/EN) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Full PT-BR/EN i18n for jotter — locale synced live from GrandpaSSOn on every request, writable through GrandpaSSOn's `/me/locale`, Laravel backend messages/validation localized, and all 37 Vue components converted to vue-i18n.

**Architecture:** Backend reads `locale` from GrandpaSSOn's shared `sso_users` table (already queried every request) and syncs it into jotter's own `users.locale` column for background-job use; a global middleware calls `App::setLocale()` so `__()`/validation resolve automatically. Writes proxy through GrandpaSSOn's `POST /me/locale` (CSRF+audit already built there) then mirror into the local column. Frontend wires vue-i18n with nested-by-feature keys, boots the locale from `/auth/me`, and exposes a header toggle. Two Vue components are converted as fully-worked exemplars; the remaining 35 follow the exact same documented procedure, verified per-file by existing test suites + typecheck + a zero-hardcoded-string grep.

**Tech Stack:** Laravel 12 (PHP 8.2+), Vue 3 + vue-i18n 9, Vitest, PHPUnit, MySQL (shared with GrandpaSSOn via table prefix).

## Global Constraints

- Supported locales: exactly `pt-BR` (default) and `en` — matches GrandpaSSOn's `Locale::SUPPORTED`.
- Locale write path goes through GrandpaSSOn's `POST /me/locale` (never a direct SQL write to `sso_users`) — see design spec §2.
- `users.locale` on jotter's own table is a write-through cache for background jobs/emails, refreshed on every SSO login — see design spec §1.
- Test-suite English strings must stay byte-identical to their current hardcoded values wherever a test currently asserts on rendered text — the test environment's default i18n locale is `en`, not `pt-BR`, specifically so none of the 54 existing Vitest spec files need their assertions rewritten.
- No email code changes — `app/Mail/` doesn't exist yet (design spec §5); nothing to convert.
- `McpController`'s JSON-RPC error messages are protocol-level (machine-consumed), not localized — excluded from backend message extraction.

<?php

namespace App\Http\Middleware;

use App\Domain\Auth\Contracts\IdentityProvider;
use Closure;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\App;
use Symfony\Component\HttpFoundation\Response;

final class SetLocaleFromSubject
{
    public function __construct(
        private readonly IdentityProvider $identityProvider
    ) {}

    /**
     * @param  Closure(Request): Response  $next

    public function handle(Request $request, Closure $next): Response

        if ($subject !== null) {
            App::setLocale($subject->locale);
        }

        return $next($request);
    }
}

`app/Http/Controllers/UserLocaleController.php`:

```php
<?php

namespace App\Http\Controllers;

use App\Domain\Auth\Contracts\IdentityProvider;
use Illuminate\Http\JsonResponse;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Http;

final class UserLocaleController extends Controller
{
    private const SUPPORTED_LOCALES = ['pt-BR', 'en'];

    public function __construct(
        private readonly IdentityProvider $identityProvider
    ) {}

    public function update(Request $request): JsonResponse
    {
        $subject = $this->identityProvider->resolveIdentity($request);

        if (! $subject) {
            return response()->json(['message' => 'Unauthenticated.'], 401);
        }

        $locale = (string) $request->input('locale', '');
        if (! in_array($locale, self::SUPPORTED_LOCALES, true)) {
            return response()->json([
                'message' => 'locale must be one of: '.implode(', ', self::SUPPORTED_LOCALES),
            ], 400);
        }

        if (($subject->attributes['sso_provider'] ?? null) === 'grandpasson') {
            $synced = $this->syncViaGrandpaSson($request, $locale);
            if (! $synced) {
                return response()->json(['message' => 'Failed to update locale on GrandpaSSOn.'], 502);
            }
        }

        $subject->user?->update(['locale' => $locale]);

        return response()->json(['ok' => true, 'locale' => $locale]);
    }

    private function syncViaGrandpaSson(Request $request, string $locale): bool
    {
        $baseUrl = rtrim((string) config('jotter.sso.broker_base_url'), '/');
        $cookie = $request->cookie('AUTHSESSID') ?? ($_COOKIE['AUTHSESSID'] ?? null);
        if ($baseUrl === '' || $cookie === null) {
            return false;
        }

        $getResponse = Http::withHeaders(['Cookie' => "AUTHSESSID={$cookie}"])
            ->get("{$baseUrl}/me/locale");
        if (! $getResponse->successful()) {
            return false;
        }

        $csrf = (string) ($getResponse->json('csrf') ?? '');
        if ($csrf === '') {
            return false;
        }

        $postResponse = Http::withHeaders(['Cookie' => "AUTHSESSID={$cookie}"])
            ->asForm()
            ->post("{$baseUrl}/me/locale", ['csrf' => $csrf, 'locale' => $locale]);

        return $postResponse->successful();
    }
}
```

import { useI18n } from 'vue-i18n'
import { updateLocale } from '../services/api'

export function useLocale() {
  const { locale } = useI18n({ useScope: 'global' })

  async function setLocale(newLocale: string) {
    locale.value = newLocale
    try {
      await updateLocale(newLocale)

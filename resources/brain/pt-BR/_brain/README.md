# Brain — por onde começar

Este workspace é o cérebro compartilhado entre pessoas e agentes de IA. Tudo é Markdown comum: dá para abrir no Jotter, no Obsidian ou em qualquer editor.

| Pasta | O que guarda | Quem escreve |
| --- | --- | --- |
| `projetos/<slug>/estado.md` | Estado de cada projeto: status, última decisão, próximo passo | Pessoas (agentes só sugerem pelo `inbox/`) |
| `decisoes/AAAA-MM-DD-<slug>.md` | Decisões datadas, uma por arquivo | Pessoas |
| `diario/AAAA-MM-DD.md` | Diário do dia; cada agente acrescenta o que fez | Agentes só acrescentam |
| `inbox/<cliente>/` | Rascunhos, achados e propostas de cada agente | O agente daquele cliente |
| `pessoas/<nome>.md` | Quem é quem, contexto e preferências | Pessoas |
| `_brain/` | Este roteador e as regras dos agentes | Só pessoas |

A consolidação do `inbox/` nas pastas oficiais é feita por uma pessoa, ou por um agente com um token de caminhos mais amplos emitido para isso.

# ADR-005: Branding por configuração

## Contexto
O mesmo motor é oferecido como software livre e como serviço hospedado.

## Decisão
Nome, logo, links legais e estado do plano são configuração e dados — nunca um fork. Os padrões deixam a instalação auto-hospedada idêntica.

## Consequências
- Um único artefato de release para os dois públicos.
- Cobrança fica fora do motor; o operador reflete o resultado com um comando.
